Как установить

Обычный установщик: запустили, нажали «Установить», закрыли. Всё остальное он сделает сам.

  1. Скачайте установщик MS-1.1-Setup.exe — это один файл, около 300 КБ.
  2. Запустите его. «Установить сейчас» поставит MS в стандартную папку, «Настроить установку» позволит выбрать папку, ярлыки, ассоциацию .ms и команду ms в PATH.
  3. Нажмите «Установить» и дождитесь надписи «Установка завершена».
  4. Готово. Файлы .ms открываются двойным щелчком, команда ms работает в командной строке, а в меню «Пуск» появляется «Центр MS» — расширения, настройки и учебник.

Если при запуске Windows покажет синее окно SmartScreen, нажмите «Подробнее» → «Выполнить всё равно». Установщик пока не подписан сертификатом — это обычное предупреждение для небольших программ.

Системные требования

  • Windows 7, 8, 8.1, 10 или 11 (64-бит).
  • Около 1 МБ на диске.
  • Права администратора не нужны.
  • Python и другие библиотеки не требуются.

Что можно выбрать

  • Папку установки — по умолчанию %LOCALAPPDATA%\Programs\MS.
  • Ярлык в меню «Пуск» и на рабочем столе.
  • Ассоциацию файлов .ms.
  • Команду ms в PATH.
  • Ярлык «Центр MS» — расширения, настройки, учебник и редактор.
Без установки

Портативный режим

Можно вообще не устанавливать MS: положите ms.exe рядом с файлом программы и запускайте.

Запуск из папки с движком
ms.exe привет.ms
ms.exe --help
ms.exe --version

Портативному режиму не нужны ни реестр, ни PATH — только сам движок и ваш файл .ms.

Автоматизация

Тихая установка

Для скриптов и развёртывания у установщика есть ключи. Окно мастера не появляется.

КомандаЧто делает
MS-1.1-Setup.exe /SУстанавливает MS в стандартную папку без вопросов.
MS-1.1-Setup.exe /S /D=C:\MSТихая установка в указанную папку.
MS-1.1-Setup.exe /uninstallОткрывает мастер удаления с подтверждением.
MS-1.1-Setup.exe /S /uninstallУдаляет MS без вопросов.

Ключи можно писать в любом регистре: /s, /d=, /Uninstall.

Удаление

Удалить MS полностью

Мастер удаления снимает движок, ярлыки, ассоциацию и записи PATH. Ваши файлы .ms остаются на месте.

Через мастер

Запустите MS-1.1-Setup.exe /uninstall и нажмите «Удалить». Мастер покажет папку, из которой удаляет MS.

Без вопросов

Команда MS-1.1-Setup.exe /S /uninstall удалит всё молча — удобно для скриптов.

Что удаляется

Движок, ярлыки в меню «Пуск» и на рабочем столе, ассоциация .ms, запись в PATH и настройки в реестре.

Помощь

Если что-то не так

Четыре частые ситуации — и что с ними делать.

Windows предупреждает

SmartScreen покажет синее окно, потому что установщик не подписан. Нажмите «Подробнее» → «Выполнить всё равно».

Команда ms не найдена

Закройте и откройте командную строку заново. Если не помогло — переустановите MS с включённым пунктом «Добавить ms в PATH».

Файлы .ms не открываются

Ассоциацию можно включить при установке. Или нажмите на файл правой кнопкой → «Открыть с помощью» → выберите ms.exe.

Русский текст в программе

Сохраняйте файл .ms в UTF-8. В Блокноте это «Сохранить как» → кодировка UTF-8.
