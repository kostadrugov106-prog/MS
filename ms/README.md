# MS — русский язык программирования

MS — учебный язык программирования с русскими командами. Движок написан на C,
не использует Python и работает на Windows 7–11 без установки зависимостей.
Текущая версия — 1.1 (стабильный выпуск): Центр MS, расширение «Веб», редактор, словари.

## Что в папке

```
ms\
├─ движок\              исходник ms.c, ресурсы, собранный ms.exe
│  ├─ ms.c
│  ├─ ресурс.rc         иконка и сведения о версии
│  ├─ icon-small.ico
│  ├─ ms.exe
│  └─ собрать_движок.ps1
├─ тесты\               13 программ .ms для проверки языка
├─ установщик\          мастер установки на C
│  ├─ ms_setup.c
│  ├─ ресурс.rc
│  ├─ build.ps1
│  └─ MS-1.1-Setup.exe
├─ сайт\                статический сайт (8 страниц + 404)
│  ├─ index.html, language.html, install.html, docs.html,
│  │  faq.html, versions.html, extensions.html, brand.html
│  ├─ assets\           стили, логотип, картинка для соцсетей
│  ├─ download\         MS-1.1-Setup.exe и пример расширения
│  ├─ nginx.conf.example  настройка ЧПУ для nginx
│  ├─ .htaccess          то же для Apache
│  ├─ просмотр.ps1      локальный сервер для проверки
│  ├─ robots.txt
│  ├─ sitemap.xml
│  └─ 404.html
├─ прогнать_тесты.ps1
└─ README.md
```

## Требования

- Windows 7–11 (64-бит).
- PowerShell 5.1.
- MinGW-w64 (WinLibs POSIX MSVCRT). Скрипты сами находят его в
  `%LOCALAPPDATA%\Microsoft\WinGet\Packages`.
- Python, CMake и другие инструменты не нужны.

## Сборка движка

```powershell
powershell -ExecutionPolicy Bypass -File движок\собрать_движок.ps1
```

Скрипт копирует исходники во временную папку без кириллицы в пути
(`windres` плохо переносит русские пути), собирает ресурсы и `ms.exe`,
затем кладёт результат в `движок\ms.exe`.

После сборки проверьте свойства файла: описание должно быть
«MS — русский язык программирования», издатель — `Mazing Studio`.
Если описания нет, значит ресурсы не подключились.

## Запуск

```powershell
движок\ms.exe тесты\01_арифметика.ms
движок\ms.exe --помощь
движок\ms.exe --версия
```

Файлы программ сохраняйте в UTF-8. При запуске двойным щелчком окно
не закрывается сразу — движок ждёт Enter.

## Тесты

```powershell
powershell -ExecutionPolicy Bypass -File прогнать_тесты.ps1
```

Скрипт по очереди запускает все файлы из `тесты\` и печатает `[ OK ]`
или `[ОШИБКА]`. Если все прошли, код возврата 0. Перед прогоном
движок должен быть собран.

## Установщик

```powershell
powershell -ExecutionPolicy Bypass -File установщик\build.ps1
```

Скрипт берёт `движок\ms.exe`, который должен быть собран заранее,
и создаёт `установщик\MS-1.1-Setup.exe` (без прав администратора).

Ключи установщика:

- `/S` — тихая установка в стандартную папку;
- `/S /D=C:\MS` — тихая установка в указанную папку;
- `/uninstall` — мастер удаления;
- `/S /uninstall` — тихое удаление.

После сборки скопируйте установщик в `сайт\download\MS-1.1-Setup.exe`,
иначе кнопки скачивания на сайте отдадут старую версию.

## Сайт

Сайт статический, сборка не нужна. Он самодостаточен: установщик лежит
внутри, в `сайт\download`.

Адреса страниц — ЧПУ: `/`, `/language`, `/install`, `/docs`, `/faq`,
`/versions`, `/extensions`, `/brand`. На диске файлы остаются с `.html`;
сервер должен отдавать `install.html` по адресу `/install`.

### Выкладка на nginx

1. Загрузите **содержимое** папки `сайт` в корень сайта, чтобы `index.html`,
   `install.html`, `assets\` и `download\` лежали в одной папке.
2. Подключите `nginx.conf.example` или добавьте в свой конфиг
   `try_files $uri $uri.html $uri/ =404;` и `error_page 404 /404.html;`.
3. Проверьте конфиг: `nginx -t`, затем перезагрузите: `nginx -s reload`.
4. Откройте `https://mazing-studio.site/` и `https://mazing-studio.site/install`.

Если `/install.html` отдаёт 404 от nginx, значит файла нет по этому пути
или конфиг не отдаёт статику. После загрузки и настройки старые адреса
с `.html` будут перенаправляться на ЧПУ.

### Если своя 404 не показывается

1. `404.html` должен лежать в корне сайта рядом с `index.html`.
2. Проверьте файл напрямую: откройте `https://mazing-studio.site/404.html`.
   Видна ваша страница — файл на месте. Отдаётся стандартная 404 nginx —
   файла нет в корне или его закрывает `internal`/правило сервера.
3. Директивы `error_page` и `location @notfound` должны быть в активном
   `server { }` домена. Если панель хостинга добавляет свой `error_page`
   позже, он переопределит ваш — перенесите блок ниже include или задайте
   страницу 404 в панели.
4. Используйте вариант с `@notfound` из `nginx.conf.example`: он не зависит
   от правил ЧПУ и редиректов `.html`.
5. После правки: `nginx -t`, затем `nginx -s reload`.
6. Проверка: `curl -I https://mazing-studio.site/no-such` — код 404,
   а в теле должна быть фраза «Нет такой страницы».

Если на домене стоит CMS или конструктор, он может отдавать свою 404.
В этом случае страницу ошибки настраивают в самой CMS или в панели.

### Локальный просмотр

```powershell
powershell -ExecutionPolicy Bypass -File сайт\просмотр.ps1
```

Откройте `http://localhost:8765/`. Скрипт сам отдаёт `/install` как
`install.html`, поэтому ЧПУ работают и локально.

### Служебное

- `robots.txt` и `sitemap.xml` рассчитаны на домен `https://mazing-studio.site`.
  При смене домена поправьте адреса в этих файлах, в `<link rel="canonical">`
  и в мета-тегах Open Graph.
- `assets\og.png` — картинка 1200×630 для соцсетей. Исходник — `assets\og.html`;
  после правки текста или размеров перерисуйте её.
- `404.html` — страница для ненайденных адресов.
- `.htaccess` — то же правило для Apache, если хостинг не на nginx.

## Чек-лист публикации

1. Собрать движок: `движок\собрать_движок.ps1`.
2. Прогнать тесты: `прогнать_тесты.ps1`.
3. Собрать установщик: `установщик\build.ps1`.
4. Скопировать установщик в `сайт\download`.
5. Обновить размеры движка и установщика на страницах сайта
   (`index.html`, `language.html`, `versions.html`, `install.html`)
   и на картинке `assets\og.png`.
6. Проверить локально: `powershell -ExecutionPolicy Bypass -File сайт\просмотр.ps1`,
   открыть `http://localhost:8765/install`.
7. Загрузить содержимое папки `сайт` в корень хостинга и подключить
   `nginx.conf.example` (или включить ЧПУ в панели хостинга).
8. Проверить `https://mazing-studio.site/`, `/install`, мобильную версию и 404.
9. Проверить установку, удаление и переустановку на чистой машине.

## Правила проекта

- Интерфейс, сообщения об ошибках и сайт — на русском языке.
- Файлы программ `.ms` — в кодировке UTF-8.
- PowerShell-скрипты сохраняйте в UTF-8 **с BOM**, иначе PowerShell 5.1
  прочитает русский текст как ANSI.
- Личные данные автора не публикуются: в кредитах указывается только ник **GG**.
- Расширения языка находятся в разработке; страница `extensions.html`
  честно предупреждает, что функции пока нет.
